# Migration tracking

This folder holds the **human-edited** state of the UiPath -> AutoStation migration. Everything else is generated by
`tools/uipath/` (see [`docs/UIPATH_MIGRATION.md`](../docs/UIPATH_MIGRATION.md)).

| File | Who edits it | Purpose |
|---|---|---|
| `status.yaml` | the migration lead / project owners (via PR) | one entry per UiPath project: stage, wave, owner, target date, blockers, parity result |
| `program.yaml` | the program lead | robots + licence cost inputs for the **estimate** on the dashboard |
| `status.sample.yaml`, `program.sample.yaml` | - | synthetic examples: copy them to `status.yaml` / `program.yaml` |

Generated and *not* committed (re-create any time): `inv/inventory.{json,csv,html}`, `scaffolds/`, `parity/<project>/`, the dashboard.

```bash
python tools/uipath/inventory.py <where-your-projects-live> --out migration/inv --orchestrator-export <orchestrator export dir>
python tools/uipath/dashboard.py --inventory migration/inv/inventory.json --status migration/status.yaml --program migration/program.yaml --out migration/dash
```

## `status.yaml` schema

The file must stay inside the YAML subset `wrapper_core.miniyaml` reads (block maps/lists, `{a: b}` / `[a, b]` flow, quoted strings;
quote dates and anything that looks like a number).

```yaml
program: {name: "UiPath to AutoStation migration", updated: "2026-10-21"}   # optional
waves:                                   # optional metadata; wave keys are strings
  "1": {name: Pilot wave, target: "2026-12-15"}
projects:
  Invoice_Processing_REF:                # the UiPath project name (project.json "name") exactly
    status: pilot                        # inventoried | classified | scaffolded | in_dev | pilot | broad | retired
    wave: 1                              # any label; projects without one are "unassigned"
    owner: ap-team@example.com           # distribution list
    target_date: "2026-12-15"            # ISO date; past + not retired => shown as overdue
    effort_spent_days: 4                 # optional; remaining = planned - spent (else derived from the stage)
    blockers: ["Waiting on API access"]  # any non-empty list marks the project blocked
    parity:                              # filled in from `parity.py` runs
      verdict: GO                        # GO | NO-GO   (empty = pending)
      date: "2026-11-30"
      report: "parity/Invoice_Processing_REF/parity.html"    # http(s) URL or relative path only
    robots_retired: {unattended: 1, attended: 0}   # counted for the licence estimate only when status is `retired`
    notes: free text
history:                                 # optional: appended by whoever updates the file; drives the burn-down sparkline
  - {date: "2026-10-01", remaining_days: 21, retired: 0}
```

Stages in order: **inventoried** (found by the scanner) -> **classified** (pattern + owner agreed) -> **scaffolded**
(`scaffold.py` output committed) -> **in_dev** (dev ring, parallel run starting) -> **pilot** (pilot ring) -> **broad** (broad ring)
-> **retired** (UiPath trigger disabled, process archived, robot/licence released).

## `program.yaml` schema (licence estimate)

```yaml
licence:
  currency: USD
  annual_cost_per_unattended_robot: 8000
  annual_cost_per_attended_robot: 1500
  annual_orchestrator_cost: 20000      # counted only when every project is retired
robots: {unattended_total: 12, attended_total: 3}
```

The figures are an **estimate** from these inputs - not a quote, not a commitment. Use your contract values, not the sample numbers.
